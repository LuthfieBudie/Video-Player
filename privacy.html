Effective 20 November 2026

About this app

Video Gallery is a personal website owned by Luthfie Budie Andika that shows videos from his own Google Drive. The sync script is used only by the site owner.

Google data accessed

With the drive.metadata.readonly permission, the script only reads video file metadata (name, ID, dates, duration and starred status) from the owner's Google Drive. File contents are never downloaded, changed or deleted.

How the data is used

This metadata is only used to build the list of videos shown on the website. It is not sold, shared with third parties or used for advertising.

Visitors

Visitors don't sign in and no personal data is collected. Favorites and playlists created on the site are stored only in the visitor's own browser (localStorage).
